# 📘 FASCÍCULO 23 — REGÊNCIA VERBAL (COMPLEMENTOS DE REGIME)

## 1. Definição e Conceito

- **O que é:** Regência verbal é a relação de dependência entre um verbo e seu complemento, que pode ser direta (sem preposição) ou indireta (com preposição). No espanhol formal, muitos verbos exigem uma preposição específica para se ligar a um substantivo, pronome ou oração.
- **Por que importa para o CACD:** A prova de espanhol exige produção escrita formal (resumo, versão, opinião). Erros de regência denunciam imediatamente o falante de português e comprometem a nota de precisão linguística.

---

## 2. Regras e Casos

### Regra Geral

> Muitas palavras regem seu complemento por meio de uma preposição. Outras, porém, **não** admitem preposição antes da oração subordinada. O domínio dessas listas é essencial para a escrita formal.

### Caso 1 — Verbos que EXIGEM preposição antes de oração

| Forma incorreta | Forma correta |
| :--- | :--- |
| Confía *que* todo saldrá en condiciones. | Confía **en que** todo saldrá en condiciones. |
| Le advierto *que* ha incumplido el compromiso. | Le advierto **de que** ha incumplido el compromiso. |
| Lo *que* me refiero es a tus palabras iniciales. | **A lo que** me refiero es a tus palabras iniciales. |
| Trata *que* venga pronto. | Trata **de que** venga pronto. |
| Advérteles *que* va a venir. | Advérteles **de que** va a venir. |

### Caso 2 — Verbos que NÃO admitem preposição (queísmo inverso)

| Forma incorreta | Forma correta |
| :--- | :--- |
| Pienso *de que* no dice la verdad. | Pienso **que** no dice la verdad. |
| Me temo *de que* se va a presentar cualquier día. | Me temo **que** se va a presentar cualquier día. |

### Caso 3 — Queísmo (supressão indevida da preposição *de*)

- *Convencer **de que*** (não *convencer que*)
- *Darse cuenta **de que*** (não *darse cuenta que*)

### Caso 4 — Verbos com duplo regime

Os verbos **dudar, informar, advertir, avisar e cuidar** podem ser construídos com:
- **Complemento direto** (sem preposição), ou
- **Complemento de regime** (com preposição).

### Caso 5 — Regime de *advertir* conforme o sentido

| Sentido | Regime | Exemplo |
| :--- | :--- | :--- |
| *Darse cuenta de algo* (perceber) | Transitivo direto (sem preposição) | *Advirtió **que** no estaba acompañado.* |
| *Aconsejar / prevenir* (avisar, alertar) | Complemento de regime (com *de*) | *Le advertí **de que** tuviera cuidado.* |

### Caso 6 — Regências específicas de verbos frequentes

| Verbo | Regência |
| :--- | :--- |
| *asistir* | **a** (algo/alguien) |
| *depender* | **de** (algo/alguien) |
| *insistir* | **en / sobre** (algo) |
| *contribuir* | **a / para** (algo) + **con** (dinero/recursos) |
| *influir* | **con** (pessoas) / **en** (coisas) / **para** (finalidade) |
| *confiar* | **de / en** (algo/alguien) |
| *consistir* | **en** (algo) |

---

## 3. Atenção à Interferência do Português

| Português (coloquial) | Espanhol formal (CACD) |
| :--- | :--- |
| *Confio que vai dar certo.* | *Confío **en que** saldrá bien.* |
| *Insisti que ele viesse.* | *Insistí **en que** viniera.* |
| *Ele contribuiu para o projeto.* | *Contribuyó **al** proyecto.* (formal) |
| *Avisei ele que...* | *Le advertí **de que**...* |
| *Percebi que ele saiu.* | *Advertí **que** salió.* |

**Alerta:** O português usa frequentemente a estrutura *verbo + que* onde o espanhol formal exige *verbo + preposição + que*.

---

## 4. Exemplos Contrastivos

| Erro comum | Versão correta |
| :--- | :--- |
| *Confía que todo saldrá.* | *Confía **en que** todo saldrá.* |
| *Le advierto que ha incumplido.* | *Le advierto **de que** ha incumplido.* |
| *Lo que me refiero es a...* | ***A lo que** me refiero es a...* |
| *Me temo de que se va.* | *Me temo **que** se va.* |
| *Pienso de que no dice la verdad.* | *Pienso **que** no dice la verdad.* |
| *Convencer que...* | *Convencer **de que**...* |
| *Darse cuenta que...* | *Darse cuenta **de que**...* |

---

## 5. Resumo para Consulta Rápida

1. **Confiar** + oração → *confiar **en que***
2. **Advertir** (avisar/prevenir) + oração → *advertir **de que***
3. **Advertir** (perceber/notar) + oração → *advertir **que***
4. **Depender** + substantivo/oração → *depender **de / de que***
5. **Insistir** + substantivo → *insistir **en / sobre***
6. **Contribuir** + resultado → *contribuir **a*** (formal) / *para*
7. **Influir** + coisas → *influir **en***; + pessoas → *influir **con***
8. **Consistir** + algo → *consistir **en***
9. **Asistir** + alguém/algo → *asistir **a***
10. **Darse cuenta** + oração → *darse cuenta **de que***
